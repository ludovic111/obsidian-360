# Technical sources

Local measurements take priority when describing this console. Historical pages may describe older support and are not guarantees of current compatibility. Exact revisions and hashes in each experiment take precedence over moving branch links below.

- [Free60 kernel patches](https://github.com/Free60Project/linux-kernel-xbox360): patch `6.18-xenon0.30` examined; inventory and hashes in `research/metadata/`.
- [Pinned linux-custom source](https://github.com/techflashYT/linux-custom/tree/a293dd19311668900eb1eeb2f6cb01dcac54f330): kernel, ALSA, PCI, Xenon platform and driver reference.
- [LibXenon video modes](https://github.com/Free60Project/libxenon/blob/master/libxenon/drivers/xenos/xenos_videomodes.h); analyzed revision `a333adef440f28b436a667be0a4f014afce6349d`.
- [Free60 video programming](https://free60.org/Modesetting/).
- [Free60 SMC](https://free60.org/Hardware/Console/SMC/).
- [Free60 memory map](https://free60.org/System-Software/Memory_Map/): historical NAND window description; our direct-read attempt hung the console.
- [Free60 boot process](https://free60.org/System-Software/Boot_Process/).
- [Free60 Xenon CPU](https://free60.org/Hardware/Console/Xenon_(CPU)/) and [Xenos GPU](https://free60.org/Hardware/Console/Xenos_(GPU)/).
- [BadUpdate](https://github.com/grimdoomer/Xbox360BadUpdate), [FreeMyXe](https://github.com/FreeMyXe/FreeMyXe), [XeLL](https://github.com/Free60Project/xell-reloaded).
- [ABadAvatar](https://github.com/shutterbug2000/ABadAvatar).
- [Reset Glitch Hack](https://free60.org/Hacks/Reset_Glitch_Hack/) and [RGH3 source](https://github.com/15432/RGH3).
- [ArchPOWER](https://repo.archlinuxpower.org/).

Third-party code is not presented as an original discovery. Large binaries, keys, and firmware dumps are not tracked. See [licensing](../THIRD_PARTY.md) for upstream attribution and extraction-based test conventions.
